- git commit -m "fix"
- git add src/validator.py
- git commit -m "update"

## Checkpoint 2
Commands:
- git log --oneline
- git revert <commit-hash>

Reflection:
I learned how git revert allows me to safely undo changes without deleting commit history, which is important for maintaining traceability.

---

## Checkpoint 3
Commands:
- git checkout main
- git commit -m "Add is_positive helper function"
- git reset --hard HEAD~1
- git checkout feature/119804919
- git cherry-pick <commit-hash>

Reflection:
I learned how cherry-pick can move specific commits between branches, which is useful when work is committed on the wrong branch.

---

## Checkpoint 4
Commands:
- git checkout -b experiment/119804919
- git commit -m "experiment: test reflog recovery"
- git branch -D experiment/119804919
- git reflog
- git checkout -b recovered/119804919 <commit-hash>
- git merge recovered/119804919

Reflection:
I learned how git reflog can recover lost commits even after a branch is deleted, which is very powerful for undoing mistakes.

---

## Checkpoint 5
Commands:
- git remote add upstream <url>
- git fetch upstream
- git checkout main
- git reset --hard upstream/main
- git checkout feature/119804919
- git rebase main
- git push --force-with-lease

Reflection:
I learned how rebasing keeps commit history linear and how syncing with upstream keeps my branch up to date with the latest changes.

---

## Checkpoint 6
Commands:
- git log main..HEAD --oneline
- git rebase -i main
- git push --force-with-lease

Reflection:
I learned how interactive rebase can clean up commit history by rewording, squashing, and reorganizing commits before submission.
